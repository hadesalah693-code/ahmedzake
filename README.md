# الوسام للخدمات الجامعية

نظام إدارة الإيرادات والمصاريف والأرشفة مع تسجيل دخول وأدوار.

## تسجيل الدخول الافتراضي

| الحقل | القيمة |
|--------|--------|
| اسم المستخدم | `admin` |
| كلمة المرور | `admin123` |

**غيّر كلمة المرور فوراً** من الإعدادات ← إدارة المستخدمين.

## الأدوار

| الدور | الصلاحيات |
|--------|-----------|
| **مدير** | كل شيء + إدارة المستخدمين والإعدادات |
| **موظف** | طلبات، أرشيف، تقارير |
| **محاسب** | مصاريف، تقارير |

## التشغيل المحلي

```bash
# انسخ ملف البيئة
copy .env.example .env

# ثبّت الحزم
pip install -r requirements.txt

# شغّل
python app.py
```

أو انقر على **`start.bat`**

## الرفع على استضافة Render (مجاني)

1. أنشئ حساب على [render.com](https://render.com)
2. اربط مستودع GitHub بالمشروع
3. اختر **New → Blueprint** وارفع `render.yaml`
4. عيّن `ADMIN_PASSWORD` بكلمة مرور قوية
5. عيّن `SECRET_KEY` عشوائي طويل
6. بعد النشر افتح الرابط وادخل بحساب المدير

## رفع على VPS (موصى به للإنتاج)

```bash
pip install -r requirements.txt
gunicorn wsgi:app --bind 0.0.0.0:5000 --workers 2
```

استخدم **Nginx** كوكيل أمامي مع **HTTPS** (Let's Encrypt).

## متغيرات البيئة

| المتغير | الوصف |
|---------|--------|
| `SECRET_KEY` | مفتاح سري للجلسات (إجباري على الاستضافة) |
| `ADMIN_USERNAME` | اسم مدير النظام (افتراضي: admin) |
| `ADMIN_PASSWORD` | كلمة مرور المدير الأولى |
| `PORT` | المنفذ (افتراضي: 5000) |
| `DATA_DIR` | مجلد البيانات والملفات |
